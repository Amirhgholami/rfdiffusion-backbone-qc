# RFdiffusion Backbone QC

A Python toolkit for assessing basic structural properties of protein backbones generated by RFdiffusion.

## Overview

This project provides an initial, reproducible workflow for evaluating protein backbone structures using geometric measurements and backbone dihedral angles.

The goal is to help identify potential structural irregularities before proceeding to more advanced structural analyses.

## Current Features

- Parse protein structures from PDB files.
- Calculate the radius of gyration using Cα coordinates.
- Check distances between consecutive Cα atoms to flag potential backbone discontinuities.
- Calculate backbone phi (φ) and psi (ψ) dihedral angles where the required atoms and peptide-bond geometry are available.
- Export summary metrics to CSV.
- Run automated tests with pytest.

## Installation

Python 3.10 or newer is required.

Clone the repository:

```bash
git clone https://github.com/Amirhgholami/rfdiffusion-backbone-qc.git
cd rfdiffusion-backbone-qc
```

Create and activate a virtual environment, then install the project:

```bash
python -m venv .venv
```

On Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

## Usage

Place the PDB structures you want to analyze in the `input/` directory.

Run the analysis:

```bash
python -m backbone_qc.main
```

The summary CSV is written to:

```text
results/backbone_metrics.csv
```

Run the test suite:

```bash
python -m pytest -v
```

## Output Metrics

| Metric | Description |
|---|---|
| `n_residues` | Number of analyzed residues |
| `radius_of_gyration_A` | Cα-based radius of gyration in angstroms |
| `n_flagged_ca_distances` | Number of consecutive Cα distances outside the configured range |
| `n_phi_angles` | Number of calculated phi angles |
| `n_psi_angles` | Number of calculated psi angles |
| `fraction_residues_with_phi_psi` | Fraction of analyzed residues with both angles available |

## Scientific Scope and Limitations

This is an early-stage structural quality-control project.

The current metrics can help identify some geometric irregularities, but they do **not** establish that a designed protein binder folds correctly, binds its target, or has biological activity.

The current workflow does not yet provide comprehensive Ramachandran validation, secondary-structure assignment, steric-clash analysis, or binding-interface evaluation.

Results should therefore be interpreted as preliminary geometric checks rather than a complete assessment of protein quality.

## Data and Privacy

Input structures and generated results are excluded from version control by default. Do not publish confidential protein sequences, target structures, or unpublished design data without appropriate authorization.
